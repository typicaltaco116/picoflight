# Source file logical organization

## actuators
Contains source files pertaining to the control outputs of the flight
controller.

## estimation
Includes code regarding the attitude and position estimation
algorithms required for sensor fusion and filtering.

## orientation
Contains code defining the sensor frame of the flight controller.

## RC
Includes code for interfacing with radio control equipment and 
telemetry.

## sensors
Defines source files for interfacing with physical sensor hardware and
abstracting their low level behavior.

## stability
Implements control loops for maintaining stability in flight.
